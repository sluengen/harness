### Changed — the reclaim test family is split along its production seams (#274)

`reclaim` is decomposed across four production modules, but all four were tested
from one 2,774-line module — 3.7x the declarative ceiling, and the highest-churn
test file in the repo, so every reclaim ticket paid the navigation cost. The
`close` and `review` families were decomposed in the same period and each
extraction got its own test module; `reclaim` was the outlier.

It now follows the same convention:

- `tests/unit/test_reclaim_undo.py` — the `--undo` arm (#254)
- `tests/unit/test_reclaim_liveness.py` — the #216 ledger and #254 worktree clocks
- `tests/unit/test_reclaim_closable.py` — the #255 closable classifier
- `tests/unit/test_cli_reclaim.py` — the verb's own surface, 2,774 -> 790 lines
- `tests/_reclaim.py` — the fixtures the four arms share, following the
  `tests/_ledger.py` pattern

This is a pure test-structure move: no production code changed, and all 96
reclaim test names are preserved exactly across the split.

The residual verb module is 790 lines — 40 over the ceiling — and carries a
`# size:` marker saying so, replacing the one that claimed the four arms were
unsplittable. What remains has no production seam left to split on; the marker
names the one block that could still be rehomed and why #274 did not do it.
