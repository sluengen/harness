### Fixed — release-cadence bounds no longer halt the build queue (#350)

The `changelog.d/` count bound and `CHANGELOG.md`'s size ratchets moved from the pytest stage of `scripts/verify.sh` to `scripts/cadence.py`, which the release path enforces (`check`) and the gate only reports (`report`, always exit 0). A breach describes accumulated repo state that no single change caused or can fix; inside the gate it made `verify.sh` red on `origin/dev` independent of any diff, so `review` refused every ticket and five consecutive build ticks shipped nothing. The per-change half the ratchet caught in passing — an append under `## [Unreleased]` — stays in the gate as `test_unreleased_window_carries_no_new_entries`.
