### Changed — the claude review engine runs on opus (#374)

`loop.review_model` moves `sonnet` → `opus`, with `DEFAULT_REVIEW_MODEL` in
lockstep, so a repo carrying no `loop:` block of its own runs the new alias too.
`harness review --model <alias>` still overrides it, and `design` is unchanged —
it has run on opus since ADR 0007.

Interim, pending the review-verb timing work. No timing benefit is claimed and
the knob's comment says so: measured the same day, opus reviews average 599s
against sonnet's 475s, so against the unchanged 720s `engine_timeout_seconds`
this raises exposure to the ceiling rather than relieving it. The case is
verdict quality on a repo of this size.
