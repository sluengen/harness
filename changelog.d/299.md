### Changed — the attended-run spend scope is recorded where it is read (#299)

ADR 0011 scoped `loop.wall_clock_budget_minutes` to unattended runs, but the prose
that *defines* the knob still opened universal — in `CONTEXT.md`, in the
`templates/CONTEXT.template.md` block every self-hosting repo inherits, and in the
`commands/harness.md` stop rule an orchestrating session reads while deciding
whether a breaker refusal is legitimate. Each now states the mode it bounds in the
sentence that defines it, and names `loop.attended_idle_minutes` as where the other
half of the rule lives.

`specs/features/verb-model.md` recorded `reclaim --stale` as "the remaining reader"
of the mode; both readers have shipped, so it now says so and names the routine-path
guard. ADR 0011's status line and the source proposal's `status:` record the five
changes that implemented it, completing its breakdown.

Two new guards keep the correction from eroding: the wall clock's comment must scope
itself in its *first* sentence (a whole-comment containment test passes on the exact
defect, so the predicate is positional), and every sentence in `commands/harness.md`
naming the knob must name the mode it bounds.
