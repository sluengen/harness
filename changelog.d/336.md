### Changed — the test suite gains honest dependency tiers, derived not declared (#336)

CODE-4: one module carried `integration` while ~89 under `tests/unit/` spawned
processes, opened the ledger or drove whole verbs through `CliRunner`, so there
was no fast signal to select. `tests/_tiers.py` now derives each module's tier
from the boundary its module-level imports cross and `tests/conftest.py` applies
it at collection — no marker line in 250 modules to forget. Three tiers, not
two: a two-way split has to put the ~140 tree-reading guards somewhere and both
homes re-create the dishonesty, so `guard` names the boundary they do cross, the
read-only checkout. Measured: `-m "unit or guard"` is 2,869 tests in ~10s
against the whole suite's ~284s.

Structural classification is half of it. A test can reach a boundary through
*production* code, which no import scan sees — `test_cli_serve.py` drives a real
socket server that spawns a stubbed `docker` while importing neither
`subprocess` nor `CliRunner`. So a `unit`-tier test that spawns a process or
opens a database now fails with `TierViolationError`. The four modules that miss
structurally are named in `OVERRIDES`, each found by running the suite with the
denial active, and each held to still name live code, still change the answer,
and only ever widen.

No files move: relocating ~89 modules would break the retirement guards' own
path literals and strand the `tests/unit/...` citations across `SPEC.md`,
`RUNBOOK.md` and `specs/**`. So `tests/unit/` outlives its meaning, and the
answer is that it carries no authority — the classifier never reads the
directory, and a test pins that. The gate is untouched and pinned untouched:
`scripts/verify.sh` passes no `-m` and keeps the whole-population coverage
floor.

Two departures from the design, both widening: the tree detector reads
`__file__` anywhere rather than only at module level (module-level-only left 32
tree-reading guards in `unit`), and the guard splits across two modules so the
runtime denial is demonstrated from inside the tier that installs it.

### Removed — the `slow` marker (#336)

34 tests in two modules, selected by nothing in CI or the gate, and both modules
drive real repositories — a second, weaker name for `integration` resting on an
unmeasured judgment about speed. Every test it marked is now `integration` by
dependency.
