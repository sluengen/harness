### Added — every verb takes an explicit `--repo`; the implicit CWD form is deprecated (#306)

A verb's target repo arrived only through the ambient working directory, so an
invocation meant something different depending on where the calling shell
happened to be — which broke verb calls on five separate occasions. Every
command except `version` now accepts `--repo <path>`, and omitting it writes one
deprecation line to stderr while behaving exactly as before. stdout is
byte-identical to the explicit form, so the JSON contract the orchestrating loop
parses is untouched (ADR 0012).

The omitted-argument default is `None` rather than `Path(".")` — the only way to
tell omission from an explicit `--repo .` — and the CWD is read at one seam,
`harness/cli/_repo.py`, guarded so no other module in `harness/cli/` reads it.
`worktrees` keeps `--repo-root` as a second name on the same parameter.

`docker/harness-wrapper.sh` cannot forward an explicit `--repo` yet, so
invocations through `~/bin/harness` stay implicit for now; `RUNBOOK.md` records
that prerequisite and the out-of-repo callers an operator must update before the
implicit form is removed.
