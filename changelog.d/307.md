### Added — `harness serve`: a persistent host process spawning one-shot verb containers (#307)

ADR 0012's runtime host. `harness/hostenv/spawn.py` becomes the one home for
`docker run` construction, shared by the socket path and the client's
direct-spawn fallback so the two cannot drift into different security postures.
The spawner's load-bearing property — the caller never specifies the mount,
image, privilege or env — is enforced positionally: every caller-derived token
lands after the image, where docker parses a command rather than options.
