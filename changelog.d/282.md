### Fixed — no live doc hand-lists a subset of the event-payload class set (#282)

`specs/features/run-ledger.md` named eight typed payload contracts in one comma run while
`harness/events/payloads.py` defined ten. The two it omitted — `CloseFailureEventData` (#263's
close-refusal telemetry) and `ReclaimUndoneEventData` (#254) — appeared nowhere in `specs/`, and one
of them describes a close-gate surface. This is the enumeration idiom the repo has mechanized twice
before (#219/#220): a hand-written set of guarded subjects falls behind silently, and the guard then
reads green because it never checked. The existing lock covers hand-listed *commands*; nothing
covered the payload models.

The list is deleted rather than corrected. The paragraph keeps the rule it exists to state — the
emitter builds the model, a reader imports the field-derived constant — and names the module as the
set. A complete list would have been a second copy of a set with one home, true only for as long as
a test said so, and every payload model added would have become a two-file edit.

A new guard derives the class set by **importing** `harness.events.payloads` (the same fact mypy
checks, so it cannot disagree with the code) and scans the live-doc corpus for enumerations. What it
flags is a *run* — two or more backticked `*EventData` tokens joined only by whitespace, `,`, `/` or
`and` — whose names are not the whole set. A lone reference is left alone, because `run-ledger.md`
legitimately names `ReviewRefusalEventData` when arguing why the refusal shape is a separate model,
and two proposals each name one model in passing; flagging per-document would have made those false
positives and pressured authors to delete prose that says something. Comparing by equality rather
than containment catches both drift directions: a subset, and a name `payloads.py` no longer
defines.

The corpus is `_live_docs()` imported from the existing lock, not re-derived — a second guard that
re-derived a narrower corpus is how a doc sat unguarded for a full assessment cycle (#249/#252) — and
a floor test reads the captured parametrize mark so narrowing it to a hand-list fails instead of
silently dropping most of the corpus. A non-vacuity check pins the derivation: with it broken, every
doc case passes vacuously, which is the failure mode this guard family keeps rediscovering.
