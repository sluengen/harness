# 05 · Patterns

Reusable compositions of primitives (layer 04) that solve one recurring UI
problem — a card grid, a labelled-value list, a step sequence.

`docs/index.html` repeats a few compositions today (the loop-card grid, the
`grid2` label/value pairs, the arrow-joined step list) that would become
patterns if primitives existed to compose. They don't yet (layer 04 is also
a scaffold), so there is nothing to document at this layer independently of
that one.

> Scaffold. Fills in once layer 04 has real primitives to compose — a
> pattern with no primitives beneath it would just be prose describing CSS
> that already exists, which is not what this layer is for.
